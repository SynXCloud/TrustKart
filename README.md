## 🚀 STARTING YOUR ADVENTURE (Setup Guide)

### ⚔️ Prerequisites — Gear Up First

Make sure you have these weapons equipped:

- **Node.js** v18+ *(Minimum Level Required)*
- **MongoDB Atlas** account *(Your Database Realm)*
- **Cloudinary** account *(Your Media Vault)*
- **Razorpay** account *(Payment Magic)*
- **Git** *(Version Control Sword)*

---

### 🗝️ Step 1 — Enter the Realm (Clone the Repo)

```bash
git clone https://github.com/yourusername/trustkart.git
cd trustkart
```

---

### 🧪 Step 2 — Brew the Potions (Install Dependencies)

```bash
# Install backend dependencies
cd server
npm install

# Install frontend dependencies
cd ../client
npm install
```

---

### 📜 Step 3 — Configure the Secret Scroll (.env)

Create a `.env` file in the `/server` folder:

```env
# ═══════════════════════════════════
# 🔐 TrustKart — Secret Scroll
# ═══════════════════════════════════

# Server
PORT=5000
NODE_ENV=development

# Database (MongoDB Atlas)
MONGO_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/trustkart

# JWT Magic Key
JWT_SECRET=your_super_secret_jwt_key_here
JWT_EXPIRES_IN=7d

# Google OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# Cloudinary (Media Vault)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Razorpay (Payment Magic)
RAZORPAY_KEY_ID=your_razorpay_key
RAZORPAY_KEY_SECRET=your_razorpay_secret

# Frontend URL
CLIENT_URL=http://localhost:5173
```

---

### ⚡ Step 4 — Enter the Battle (Run the App)

```bash
# Start Backend Server (Port 5000)
cd server
npm run dev

# Start Frontend (Port 5173) — open a new terminal
cd client
npm run dev
```

> 🎮 **Your quest begins at:** `http://localhost:5173`

## 🎲 GAME MECHANICS (Core Logic)

### Trust Score Engine

```javascript
// 🧮 The RPG Stat Calculator
function calculateTrustScore(seller) {
  const {
    avgRating,          // ⭐ 0-5
    deliverySuccessRate, // 📦 0-100%
    returnRate,          // 🔄 0-100% (lower = better)
    reviewCount,         // 📝 total reviews
    sellerAgeMonths      // ⏰ months on platform
  } = seller;

  const ratingScore    = (avgRating / 5) * 30;
  const deliveryScore  = (deliverySuccessRate / 100) * 25;
  const returnScore    = ((100 - returnRate) / 100) * 20;
  const reviewScore    = Math.min(reviewCount / 50, 1) * 15;
  const ageScore       = Math.min(sellerAgeMonths / 12, 1) * 10;

  return Math.round(ratingScore + deliveryScore + returnScore + reviewScore + ageScore);
}

// Rank Assignment
function getRank(score) {
  if (score >= 81) return "👑 Grandmaster Seller";
  if (score >= 61) return "🛡️  Verified Knight";
  if (score >= 31) return "⚔️  Guild Apprentice";
  return "💀 Unproven Trader";
}
```
